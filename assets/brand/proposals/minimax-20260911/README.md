# MiniMax icon inspiration — 2026-09-11

Generated with authenticated `mmx 1.0.25` and MiniMax `image-01`, one image per
prompt, without the prompt optimizer. These are exploratory references only and
are not consumed by the application.

- `concept-m1-minted-exchange-leaves.png` — rejected: MiniMax replaced exchange
  arrows with a four-leaf cluster and added long shadows.
- `concept-m2-gold-coin-swap.png` — useful gold treatment, but collapsed the two
  arrows into one double-headed line and omitted the brand detail.
- `concept-m3-orbiting-exchange-coin.png` — best MiniMax composition: gold coin
  plus two circular directions. Rejected as final art because the rendering is
  glossy/3D and the central seed resembles a coffee bean.

The prompts consistently made the coin dominant, required a clear two-way
exchange cue, limited Honest Fern to a minor detail, and prohibited text,
currency signs, charts, growth imagery, shadows, gloss, bevels, and gradients.
The model did not consistently follow those finish constraints, so its output
is useful for composition only.
